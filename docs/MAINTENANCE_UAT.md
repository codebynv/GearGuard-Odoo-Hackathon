# Maintenance User Acceptance Tests

- [ ] Create equipment with a unique identifier.
- [ ] Reject duplicate identifiers.
- [ ] Create a maintenance request for valid equipment.
- [ ] Start work and verify the equipment state.
- [ ] Complete the request with a resolution.
- [ ] Confirm equipment returns to the expected state.
- [ ] Verify due preventive plans are visible.
- [ ] Confirm dashboard counts match the records.

Record failures with the test step, expected result, and actual result.

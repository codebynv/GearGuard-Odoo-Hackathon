# Contributing

GearGuard is an Odoo-based maintenance management project built for the Odoo × Adani University Hackathon.

## Development workflow

1. Create a focused branch from `main`.
2. Keep changes scoped to one feature, fix, or documentation update.
3. Test Odoo module changes in a local Odoo 18 environment before opening a pull request.
4. Update documentation when behavior, setup, or configuration changes.
5. Never commit secrets, local environment files, generated logs, or Python cache files.

## Pull requests

Include:
- what changed,
- why it changed,
- how it was tested,
- any Odoo configuration or database notes.

## Commit messages

Use concise, descriptive messages such as:

```text
feat: add preventive maintenance rule
fix: validate maintenance request dates
docs: update setup instructions
```

# Upgrade Checklist

Before upgrading the Odoo environment:

- [ ] Back up the database and relevant attachments.
- [ ] Review module dependencies.
- [ ] Test the upgrade in a non-production database.
- [ ] Inspect logs for migration errors.
- [ ] Verify equipment and maintenance records.
- [ ] Confirm scheduled actions still run.
- [ ] Document any manual follow-up.

Do not treat a successful module installation as proof that existing data and workflows are correct.

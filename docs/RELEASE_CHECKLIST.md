# Release Checklist

Before a GearGuard demo or release:

- [ ] Run the main equipment workflow.
- [ ] Verify maintenance state transitions.
- [ ] Test preventive maintenance generation.
- [ ] Check dashboard metrics.
- [ ] Review access-control behavior.
- [ ] Confirm local environment files and secrets are excluded.
- [ ] Review the final repository diff.

Document any known limitation before sharing the build.
